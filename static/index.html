Device Connections

Enter the addresses of your projector and the Raspberry Pi running PGenerator (or click Scan Network to find them automatically), then click Save & Test. Saving is what makes the calibration run use these addresses — testing alone doesn't store them.

Connect a USB-serial adapter + DB9-to-3.5mm cable to the TV's ExLink jack, and enable it in the service menu (TV off → Mute-1-8-2-Power → Control → Sub Option → EXT Link Support: ON). Then verify the command set once with python scripts/exlink_spike.py --port <port> — the TV can't report its settings back, so before the first run also reset Expert Settings → White Balance to defaults so the app starts from a known state. Current support: SDR, White Balance phase only.
Connect the projector's RS-232C port (D-Sub 9-pin) to your machine via a USB-to-serial adapter. FTDI-based adapters (FT232R) are recommended. On macOS the port appears as /dev/cu.usbserial-XXXXXXXX.

    2
    Command Probe (first run only)

    Epson doesn't publish the 5040UB's command names, and they vary by firmware. The probe asks your projector which tokens it understands and saves them to configs/command_table.json — calibration can't adjust anything without them. Run it once; the green check sticks for future sessions.

    4
    Colorimeter Placement (CCDIS3)
    • ⚪
      Remove the white diffuser lens cap from the CCDIS3
      The CCDIS3 has a projector measurement mode — it does NOT use the suction-cup flush contact method. The lens must be uncapped to receive projected light.
    • ⚪
      Mount colorimeter on a tripod, centered on screen
      Position horizontally and vertically centered on the projected image area. Typical distance: 6–18 inches from the screen surface. Aim the sensor face directly at the screen.
    • ⚪
      Ensure no direct ambient light hits the sensor face from the side
      Side-angle ambient light creates stray light contamination that skews chromaticity readings. Shield the sensor from room lights if needed.
    • ⚪
      Dim or turn off all room lights
      Ambient light adds to the projected image luminance. For accurate black/grey measurements, the room should be as dark as possible.

    Warming Up
